# Job Market & Company Analysis Dashboard

An interactive data analytics project analyzing job postings, companies, salaries, work types, experience levels, locations, applications, and engagement trends.

The project combines **Python, SQL, Power BI, and an interactive web dashboard** to transform raw job-market data into meaningful business insights.

## 📊 Dashboard

### Interactive Web Dashboard
The web dashboard allows users to explore key job-market insights directly in a browser without installing Power BI.

Add your GitHub Pages URL here after publishing.

### Power BI Dashboard

The Power BI version contains five analytical pages:

1. **Executive Overview**
   - Total Jobs
   - Total Companies
   - Total Locations
   - Total Applications
   - Total Views
   - Jobs by Work Type
   - Jobs by Experience Level
   - Remote vs Non-Remote Jobs

2. **Job Market Trends**
   - Job Posting Trend
   - Top Job Titles
   - Top Job Locations
   - Jobs by Month and Work Type

3. **Salary Analysis**
   - Average Salary by Experience Level
   - Average Salary by Work Type
   - Salary Availability
   - Top Job Titles by Average Salary

4. **Company Analysis**
   - Top Companies by Job Postings
   - Top Companies by Applications
   - Company-level job-market analysis

5. **Applications & Engagement**
   - Application Rate by Work Type
   - Application Rate by Experience Level
   - Top Locations by Applications
   - Top Job Titles by Applications
   - Views vs Applications by Work Type
